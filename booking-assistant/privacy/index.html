INTRVL Studio預約助教隱私權使用說明

PRIVACY · UPDATED 2026-10-09

隱私權政策

本說明適用於 INTRVL Studio 提供的「INTRVL 改作業預約助教」。聯絡窗口：intrvlstudio@gmail.com。

處理哪些資料

學生預約時，助教處理 Discord 使用者 ID、顯示名稱、所選時間、作業說明、預約編號與狀態，以及自願上傳的作品圖片。請勿在作品或說明中提供與批改無關的敏感資訊或他人的個人資料。

如何使用 Google 資料

僅老師需授權 Google 帳號。助教取得行事曆事件管理、行事曆忙碌狀態查詢及 Gmail 寄信權限。程式用忙碌時段避免衝突、建立或取消助教管理的預約事件，並以老師帳號向老師寄送預約、取消及開始前提醒。它不要求或使用讀取 Gmail 收件匣的權限。

Google 權限允許存取的範圍可能大於單一預約；程式僅操作設定的行事曆與助教管理的事件。既有行程的忙碌狀態用於判斷是否可預約，不會把既有行程的標題或內容提供給學生。

資料保存與接收者

預約記錄與圖片保存在老師管理的執行電腦。Google 授權憑證另存於該電腦的本機設定資料夾，供助教更新授權使用。預約資訊會傳送至老師的 Google Calendar；老師的 Gmail 通知與 Discord 私訊可能包含學生作品圖片。學生會收到自己的預約狀態與提醒。

Discord 與 Google 會依各自的條款處理在其服務中的資料。這些公開介紹頁由 GitHub Pages 託管，網站供應者可能處理必要的連線與伺服器紀錄。本助教的介紹與政策頁不另嵌入分析或廣告追蹤程式。

用途限制

助教取得的資料僅用於預約、作業批改安排、通知及故障處理，不用於廣告、出售資料或訓練 AI 模型。INTRVL 改作業預約助教對從 Google API 取得資訊的使用及轉移，遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、查詢與刪除

目前程式不會自動清除歷史預約或作品。取消預約會取消相應的 Google Calendar 事件，但不會自動刪除本機記錄、圖片，或已寄出的電子郵件與 Discord 通知。

如需查詢、更正或刪除預約及作品資料，請寄信至 intrvlstudio@gmail.com，提供 Discord 使用者 ID 或預約編號，工作室會確認身分與所需處理範圍。涉及 Discord、Google 或備份中的副本，須依各服務的功能與保存規則分別處理。

撤回 Google 授權

老師可隨時在 Google 帳戶的第三方連結移除助教授權。撤回後，助教無法繼續同步行事曆或寄信；撤回本身不會自動清除已建立的預約、圖片或通知。

更新

資料處理方式變更時，會更新本頁日期與內容。如有疑問，請聯絡工作室。
